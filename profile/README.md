## Serverless Workflow has moved!

**Serverless Workflow** has been renamed to **Open Workflow** and moved to a new GitHub organization.

### New Home

**[github.com/open-workflow-specification](https://github.com/open-workflow-specification)**

All repositories, including the specification, SDKs, and Synapse, are now under the new organization. GitHub redirects are in place, so existing links will continue to work.

### Key Links

- **[Specification](https://github.com/open-workflow-specification/specification)**
- **[SDKs](https://github.com/open-workflow-specification/specification#sdks)**: [Go](https://github.com/open-workflow-specification/sdk-go), [Java](https://github.com/open-workflow-specification/sdk-java), [.NET](https://github.com/open-workflow-specification/sdk-net), [TypeScript](https://github.com/open-workflow-specification/sdk-typescript), and more.
- **[Synapse](https://github.com/open-workflow-specification/synapse)**
